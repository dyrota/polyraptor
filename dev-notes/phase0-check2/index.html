polyraptor — Phase 0, checkpoint 2

Tests whether Pyodide can load a locally-built, vendored wheel via an absolute same-origin URL — the same mechanism the real app will use for the on_step-instrumented polysearch/polysort wheels. This uses a throwaway dummy package, not the real libraries, to isolate the wheel-loading question on its own.

Must be served over http(s), not opened as a file:// URL — run python3 -m http.server in this directory and open http://localhost:8000/.
